What the agent can do

🌍 Language detection

Identifies which language a piece of text is written in.

😊 Sentiment analysis

Classifies text as positive, negative, neutral or mixed.

🔑 Key phrases & entities

Pulls out the main ideas, people, places, dates and organizations.

🔒 PII redaction

Finds and masks personal data such as names, phone numbers and emails.

What I learned

  • Creating and configuring an AI agent in Microsoft Foundry
  • Connecting the Azure Language MCP server as an agent tool
  • Configuring tool approval settings
  • Calling the agent from Python with the Azure AI Projects SDK
  • Verifying tool calls with logs and traces
  • Keeping secrets out of source control with .env and .gitignore
